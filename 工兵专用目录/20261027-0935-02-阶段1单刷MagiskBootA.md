### 一、 执行任务

使用 9008 EDL 烧录由 Magisk 稳定版修补生成的 `magisk_boot_a.img` 到手机 `boot_a` 分区。**绝对禁止触碰 `boot_b`**（原厂备用退路）。

### 二、 核心参数与配置文件

1. **烧录镜像**：`/mnt/sda3/v50_flash_tools/magisk_boot_a.img`
   - 大小：100,663,296 字节（精确等于 24576 扇区，每扇区 4096 字节）
   - SHA256：`3ec1750cc16b54d495949b0bb634b75b7d7f57ad4e88717b9901f872ba5dc91f`
2. **烧录 XML**：`/mnt/sda3/v50_flash_tools/rawprogram_flash_magisk_boot_a.xml`
   - 目标：仅针对 `physical_partition_number="4"`（LUN 4）的 `boot_a`，`start_sector="118538"`
3. **Patch XML**：`/mnt/sda3/v50_flash_tools/patch_dummy.xml`
4. **Firehose Loader**：`/mnt/sda3/v50_flash_tools/edl_tools/loaders/000a50e100310000_e746e34f737403f4_fhprg_lg_g8x.bin`

### 三、 执行步骤

1. **进入 9008 EDL 模式**：
   - 执行 `adb reboot edl`。若设备不支持 adb 直接重启 edl，等待设备由指挥官物理组合键进入 9008，确认 `lsusb` 显示 `05c6:9008`。
2. **执行 9008 烧录**：
   ```bash
   python3 /mnt/sda3/v50_flash_tools/edl_tools/edl/edl.py qfil /mnt/sda3/v50_flash_tools/rawprogram_flash_magisk_boot_a.xml /mnt/sda3/v50_flash_tools/patch_dummy.xml /mnt/sda3/v50_flash_tools --loader=/mnt/sda3/v50_flash_tools/edl_tools/loaders/000a50e100310000_e746e34f737403f4_fhprg_lg_g8x.bin --memory=UFS
   ```
3. **复位重启设备**：
   ```bash
   python3 /mnt/sda3/v50_flash_tools/edl_tools/edl/edl.py reset --loader=/mnt/sda3/v50_flash_tools/edl_tools/loaders/000a50e100310000_e746e34f737403f4_fhprg_lg_g8x.bin
   ```
4. **等待系统启动并核验**：
   - 等待设备进入 Android 12 桌面。
   - 检验：
     - `adb shell su -c id` 是否输出 `uid=0(root)`
     - `adb shell getprop ro.boot.verifiedbootstate` 仍为 `orange`

### 四、 验收标准与交付物

- 9008 烧录成功，仅单刷了 `boot_a`；
- Android 正常启动；
- 成功获得 root 权限（`uid=0`）；
- 汇报完整输出日志。
