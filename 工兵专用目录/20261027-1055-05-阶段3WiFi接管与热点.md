### 一、 执行任务

在阶段 2 已成功启动 OpenWrt 环境与 Dropbear SSH（2222 端口）的基础上：
1. 安全停止 Android 侧的 Wi-Fi 栈服务，释放无线物理网卡控制权；
2. **严防触碰安全红线**：严禁关闭基础系统与通讯守护进程；
3. 在 OpenWrt 内部配置并启动 `hostapd`，拉起测试 AP 热点（SSID：`OpenWrt-V50-Test`，信道 1 或 36）；
4. 配置网桥与 DHCP 地址分配，供物理设备连网并验证网关连通性。

---

### 二、 最高安全红线（违反直接阻断）

- **绝对禁止停止以下服务**：
  - `adbd`（ADB 调试链路）
  - `servicemanager`、`hwservicemanager`（Android IPC 核心）
  - `vendor.cnss-daemon`（高通 WLAN 固件与子系统平台守护进程，必须保持 running！）
  - 任何 `vendor.qti.*` 基础服务、`vold`、`logd`
- 每停用一个 Android 侧服务，必须确认 `adb devices` 依然在线。

---

### 三、 执行步骤与操作规范

#### 步骤 3.1：安全停止 Android 侧 Wi-Fi 冲突服务
在宿主 Android 端执行（逐一停用）：
```bash
adb shell su -c '
setprop ctl.stop wpa_supplicant
setprop ctl.stop wificond
setprop ctl.stop vendor.wifi-hal-1-1
setprop ctl.stop vendor.wifi_hal_legacy
setprop ctl.stop vendor.wifidisplayhalservice
'
```
核验关键守护进程状态：
```bash
adb shell "getprop init.svc.cnss-daemon"
```
*必须确认输出仍为 `[running]`，且 `adb devices` 在线正常。*

#### 步骤 3.2：在 OpenWrt 内部配置测试热点
通过 SSH（2222 端口）进入 OpenWrt 配置 hostapd：
```bash
ssh -p 2222 -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null root@127.0.0.1 '
# 1. 确保接口处于空闲状态
ip link set wlan0 down
ip link set wlan0 up

# 2. 写入测试 hostapd 配置 (2.4G 信道 1, WPA2-PSK)
cat << "EOF" > /tmp/hostapd-test.conf
interface=wlan0
driver=nl80211
ssid=OpenWrt-V50-Test
hw_mode=g
channel=1
wmm_enabled=1
auth_algs=1
wpa=2
wpa_key_mgmt=WPA-PSK
rsn_pairwise=CCMP
wpa_passphrase=1234567890
EOF

# 3. 配置 wlan0 IP 地址
ip addr flush dev wlan0
ip addr add 192.168.10.1/24 dev wlan0

# 4. 配置最小 DHCP 服务 (dnsmasq)
cat << "EOF" > /tmp/dnsmasq-test.conf
interface=wlan0
dhcp-range=192.168.10.100,192.168.10.200,12h
EOF
killall dnsmasq 2>/dev/null
dnsmasq -C /tmp/dnsmasq-test.conf

# 5. 后台启动 hostapd
killall hostapd 2>/dev/null
nohup hostapd /tmp/hostapd-test.conf > /tmp/hostapd.log 2>&1 &
'
```

#### 步骤 3.3：热点运行状态与射频校验
在 OpenWrt 内部验证 hostapd 运行与射频广播：
```bash
ssh -p 2222 -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null root@127.0.0.1 '
sleep 2
ps | grep -E "hostapd|dnsmasq"
iw dev
cat /tmp/hostapd.log | tail -20
'
```

#### 步骤 3.4：物理连网测试（请总指挥或工兵配合）
- 使用手机/笔记本搜索无线网络 `OpenWrt-V50-Test`；
- 输入密码 `1234567890` 进行连接；
- 验证是否分配到 `192.168.10.x` 的 IP 地址；
- 在客户端 `ping 192.168.10.1` 确认网关连通。
