### 二、 执行步骤与命令规范

#### 步骤 2.1：只读取证
在手机端以 root 执行取证脚本：
```bash
adb shell su -c '
getprop ro.boot.slot_suffix
cat /proc/cmdline
uname -a
getenforce
ls -l /dev/watchdog*
ls -l /sys/fs/pstore
cat /sys/block/sda/queue/logical_block_size
find /proc/device-tree/firmware/android -type f | while read f; do echo "== $f"; cat "$f"; echo; done
getprop | grep init.svc | grep -iE "wifi|wlan|cnss|netd|wificond|supplicant|hostapd"
' > /tmp/evidence_host.txt 2>&1
adb shell su -c "cat /tmp/evidence_host.txt" > /tmp/v50_evidence.txt
```
同时在工作电脑端执行：
```bash
grep -n -i ramoops /mnt/sda3/v50_flash_tools/extracted_v50_boot/v50_dts.dts
```

#### 步骤 2.2：`system_b` 只读验证
在手机端挂载并提取 busybox 进行架构比对：
```bash
adb shell su -c '
mkdir -p /data/local/tmp/mnt_b
mount -t ext4 -o ro,noload /dev/block/sda25 /data/local/tmp/mnt_b
ls -l /data/local/tmp/mnt_b/sbin/init /data/local/tmp/mnt_b/bin/busybox
ls -l /data/local/tmp/mnt_b/lib | grep -i -E "ld-musl|libc"
mkdir -p /data/local/tmp/chk
cp /data/local/tmp/mnt_b/bin/busybox /data/local/tmp/chk/
chmod 644 /data/local/tmp/chk/*
umount /data/local/tmp/mnt_b
'
```
在 PC 端拉取并校验：
```bash
rm -rf /mnt/sda3/v50_flash_tools/chk
adb pull /data/local/tmp/chk /mnt/sda3/v50_flash_tools/chk
file /mnt/sda3/v50_flash_tools/chk/busybox
readelf -h /mnt/sda3/v50_flash_tools/chk/busybox | grep -E 'Class|Machine'
```
**通过标准**：架构为 AArch64（ELF 64-bit ARM aarch64），动态链接器文件存在。若不符合立即停止回报。

#### 步骤 2.3：chroot 冒烟测试
```bash
adb shell su -c '
M=/data/local/tmp/mnt_b
mkdir -p $M
mount -t ext4 -o ro,noload /dev/block/sda25 $M
mount -o bind /dev $M/dev
mount -t proc proc $M/proc
mount -t sysfs sysfs $M/sys
chroot $M /bin/sh -c "uname -a; ls /; cat /etc/openwrt_release"
umount $M/sys; umount $M/proc; umount $M/dev; umount $M
' > /tmp/smoke_test.log 2>&1
cat /tmp/smoke_test.log
```
若失败，采集：
`adb shell su -c "dmesg | grep -i avc | tail -50"` 与 `adb shell logcat -d | grep -i 'avc: denied' | tail -50`。

#### 步骤 2.4：独立命名空间拉起 OpenWrt init
确认环境：
```bash
adb shell su -c 'which unshare chroot nohup'
```
拉起接管：
```bash
adb shell su -c '
M=/data/local/tmp/lede
mkdir -p $M
mount -t ext4 -o rw /dev/block/sda25 $M
mount -o bind /dev $M/dev
mount -t sysfs sysfs $M/sys
mkdir -p $M/vendor && mount -o bind /vendor $M/vendor
nohup unshare -p -f -m chroot $M /bin/sh -c "
  mount -t proc proc /proc
  mount -t tmpfs tmpfs /tmp
  mount -t tmpfs tmpfs /run
  /usr/sbin/dropbear -R -B -p 127.0.0.1:2222 &
  exec /sbin/init
" > /data/local/tmp/lede_takeover.log 2>&1 &
'
```
等待 5 秒后，在 PC 端端口转发并测试 SSH：
```bash
adb forward tcp:2222 tcp:2222
ssh -p 2222 -o StrictHostKeyChecking=no root@127.0.0.1 "ubus list; ps"
```
**通过标准**：成功通过 SSH（端口 2222）登入 OpenWrt，`ubus list` 能输出核心服务列表。
