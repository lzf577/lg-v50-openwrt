## 二、 战术步骤与绝对命令

### 阶段 1：现役稳定系统双重备份与回退开关固化（退路保障）
1. 连通 ADB 并在手机端创建基线备份仓：
   ```bash
   adb wait-for-device
   adb shell "su -c 'mkdir -p /data/backup_baseline_v1'"
   ```
2. 在手机内部打包归档当前的 `/data/openwrt` 与开机脚本：
   ```bash
   adb shell "su -c 'cd /data && tar -czf /data/backup_baseline_v1/openwrt_old_backup.tar.gz openwrt'"
   adb shell "su -c 'cp -f /data/adb/service.d/99-openwrt-takeover.sh /data/backup_baseline_v1/99-openwrt-takeover.sh.bak'"
   ```
3. 拉取至宿主机安全目录归档：
   ```bash
   adb pull /data/backup_baseline_v1/openwrt_old_backup.tar.gz /mnt/sda3/v50_flash_tools/v50_backup/
   adb pull /data/backup_baseline_v1/99-openwrt-takeover.sh.bak /mnt/sda3/v50_flash_tools/v50_backup/
   ```

---

### 阶段 2：换装全新 LG V50 专属固件
1. 暂停接管脚本服务（避免文件占用）：
   ```bash
   adb shell "su -c 'pkill -9 -f /data/openwrt || true'"
   ```
2. 彻底清理或移动旧容器目录：
   ```bash
   adb shell "su -c 'mv /data/openwrt /data/openwrt_prev && mkdir -p /data/openwrt'"
   ```
3. 推送全新 V50 固件包并解压：
   ```bash
   adb push /mnt/sda3/ledev50/bin/targets/armsr/armv8/openwrt-armsr-armv8-lg_v50-rootfs.tar.gz /data/local/tmp/
   adb shell "su -c 'tar -xzf /data/local/tmp/openwrt-armsr-armv8-lg_v50-rootfs.tar.gz -C /data/openwrt/'"
   adb shell "su -c 'rm -f /data/local/tmp/openwrt-armsr-armv8-lg_v50-rootfs.tar.gz'"
   ```
4. 恢复基础配置与必要的设备节点/resolv.conf 链接：
   ```bash
   adb shell "su -c 'mkdir -p /data/openwrt/dev /data/openwrt/proc /data/openwrt/sys /data/openwrt/root'"
   ```

---

### 阶段 3：全新固件启动与核心功能验证
1. 触发接管脚本启动：
   ```bash
   adb shell "su -c '/data/adb/service.d/99-openwrt-takeover.sh &'"
   ```
2. 验证 LuCI Web 控制台是否就绪：
   - 检查容器内 `uhttpd` 或相关 web 服务进程是否存活。

3. 验证 ZeroTier 与 OpenClash 组件完整性：

