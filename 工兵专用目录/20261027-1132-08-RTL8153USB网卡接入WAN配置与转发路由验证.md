### 一、 关键技术研判与事实确诊

副指挥官经底层核实：
1. **驱动完全支持**：LG V50 原厂内核已深度编译并加载了 Realtek 官方 `r8152/rtl8156` 高性能驱动（版本 `v2.11.0`，驱动目录 `/sys/bus/usb/drivers/r8152`），完全原生支持 RTL8153（`0bda:8153`）；
2. **WAN 口逻辑接口**：转接卡插入后，内核将为其分配以太网接口名（通常为 `eth0` 或 `eth1`）；
3. **路由与转发核心链条**：
   - 启用内核 IPv4 转发：`echo 1 > /proc/sys/net/ipv4/ip_forward`；
   - 启动 OpenWrt 的网络管理进程 `netifd` 或由 `udhcpc` 对 WAN 网卡（如 `eth0`）进行自动 DHCP 请求，获取主路由分配的 IP 与默认网关；
   - 配置 NAT 规则（MASQUERADE），使无线客户端流量（`wlan0` `192.168.10.0/24`）经过 WAN 网卡做源地址转换顺利访问互联网。

### 三、 执行步骤与操作规范

#### 步骤 8.1：硬件接入与网卡接口检测
在转接卡与网线插好后，检测网卡接口名：
```bash
adb shell su -c '
ip link show | grep -E "eth[0-9]|usb[0-9]|enp"
dmesg | grep -iE "r8152|rtl8153|eth" | tail -20
'
```
*记录识别出的接口名称（设为 `$WAN_IF`，通常为 `eth0`）。*

#### 步骤 8.2：配置 WAN 口 DHCP 获取上级路由器 IP
进入 OpenWrt 执行（或由宿主调起 udhcpc）：
```bash
adb shell su -c '
WAN_IF=$(ip link show | grep -oE "eth[0-9]" | head -1)
if [ -z "$WAN_IF" ]; then
    echo "ERROR: 未检测到 eth 网卡接口，请检查物理连接！"
    exit 1
fi
echo "Detected WAN Interface: $WAN_IF"

ip link set $WAN_IF up
udhcpc -i $WAN_IF -b -s /etc/udhcpc.user 2>/dev/null || udhcpc -i $WAN_IF -q -n
ip addr show dev $WAN_IF
ip route
'
```

#### 步骤 8.3：启用 IPv4 路由转发与 NAT 伪装 (iptables)
在 Android 宿主执行：
```bash
adb shell su -c '
WAN_IF=$(ip link show | grep -oE "eth[0-9]" | head -1)

# 1. 开启内核转发
echo 1 > /proc/sys/net/ipv4/ip_forward

# 2. 清理并注入 NAT 规则
iptables -t nat -D POSTROUTING -o $WAN_IF -j MASQUERADE 2>/dev/null
iptables -t nat -A POSTROUTING -o $WAN_IF -j MASQUERADE

# 3. 放行转发链流量
iptables -D FORWARD -i wlan0 -o $WAN_IF -j ACCEPT 2>/dev/null
iptables -A FORWARD -i wlan0 -o $WAN_IF -j ACCEPT
iptables -D FORWARD -i $WAN_IF -o wlan0 -m state --state RELATED,ESTABLISHED -j ACCEPT 2>/dev/null
iptables -A FORWARD -i $WAN_IF -o wlan0 -m state --state RELATED,ESTABLISHED -j ACCEPT
'
```

#### 步骤 8.4：外网连通性实测
1. 从设备端 ping 外网：
   ```bash
   adb shell "ping -c 3 223.5.5.5"
   ```
2. 从已连接 `OpenWrt-V50-5G` 热点的物理手机上，打开网页或执行测速，验证是否能正常上网。

#### 步骤 8.5：固化至开机自启脚本
测试通过后，将 WAN DHCP 与 NAT 规则追加至 `/data/adb/service.d/99-openwrt-takeover.sh`，确保开机自启插上网线即连通。
