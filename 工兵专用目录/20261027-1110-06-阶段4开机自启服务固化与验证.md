   - 依赖检测（等待 Android 启动完成 `sys.boot_completed=1` 以及高通 `vendor.cnss-daemon` 就绪）；
   - 安全剥离 Android 侧冲突 Wi-Fi 栈服务；
   - 挂载 `system_b`（`/dev/block/sda25`）并进入容器隔离环境；
   - 启动 Dropbear、网络配置、`dnsmasq` 与 `hostapd` 5G 热点；
4. 进行整机物理冷重启测试，核验证明开机后无需人工干预即可自动广播热点并能物理连网连通。

### 二、 最高安全红线与防砖规范（违反直接阻断）

- **绝对禁止修改任何 boot 或底层固件分区**：阶段 4 仅操作 Magisk 用户空间脚本，不得动用 9008 刷写；
- **绝不破坏 Magisk 安全机制**：自启脚本置于 `/data/adb/service.d/`，如遇卡死，长按音量减+电源键或进入 Magisk 恢复即可规避；
- **严禁提前停止 Android 基础通信**：脚本启动时必须等待 `getprop sys.boot_completed` 达到 `1` 且等待 10 秒以上缓冲期，确保 Android 基础平台与 `cnss-daemon` 彻底就绪；
- **保持 `vendor.cnss-daemon` 与 `adbd`**：绝对禁止停用此两项服务。

### 三、 执行步骤与操作规范

#### 步骤 4.1：固化 OpenWrt 内部配置
在 Android 宿主端通过 ADB，进入当前已挂载的 OpenWrt 环境（`/data/local/tmp/lede`），将 5G 热点与 DHCP 配置永久写入 `/etc/`：
```bash
adb shell su -c '
M=/data/local/tmp/lede
mkdir -p $M/etc/hostapd

# 1. 固化 5G hostapd 配置
cat << "EOF" > $M/etc/hostapd/hostapd-5g.conf
interface=wlan0
driver=nl80211
ssid=OpenWrt-V50-5G
hw_mode=a
channel=36
ieee80211n=1
ht_capab=[HT40+]
ieee80211ac=1
vht_oper_chwidth=1
vht_oper_centr_freq_seg0_idx=42
vht_capab=[RXLDPC][SHORT-GI-80][TX-STBC-2BY1][SU-BEAMFORMER][SU-BEAMFORMEE][MU-BEAMFORMEE]
wmm_enabled=1
auth_algs=1
wpa=2
wpa_key_mgmt=WPA-PSK
rsn_pairwise=CCMP
wpa_passphrase=1234567890
EOF

# 2. 固化 dnsmasq 配置
cat << "EOF" > $M/etc/dnsmasq-v50.conf
interface=wlan0
dhcp-range=192.168.10.100,192.168.10.200,12h
EOF

chmod 644 $M/etc/hostapd/hostapd-5g.conf $M/etc/dnsmasq-v50.conf
'
```

#### 步骤 4.2：编纂并部署 Magisk 自启脚本
创建 `/data/adb/service.d/99-openwrt-takeover.sh`：
```bash
adb shell su -c '
cat << "EOF" > /data/adb/service.d/99-openwrt-takeover.sh
#!/system/bin/sh
# OpenWrt Takeover Autostart Service for LG V50

LOG_FILE=/data/local/tmp/openwrt_autostart.log
exec > "$LOG_FILE" 2>&1

echo "=== [$(date)] OpenWrt Autostart Initiated ==="

# 1. 等待 Android 系统完全启动
while [ "$(getprop sys.boot_completed)" != "1" ]; do
    sleep 3
done
echo "=== sys.boot_completed detected, waiting for cnss-daemon ==="

# 2. 等待高通 WLAN 守护进程就绪
while [ "$(getprop init.svc.cnss-daemon)" != "running" ]; do
    sleep 2
done
# 缓冲 5 秒确保平台稳固
sleep 5
echo "=== cnss-daemon ready, releasing Android Wi-Fi stack ==="

# 3. 安全停止 Android Wi-Fi 栈
setprop ctl.stop wpa_supplicant
setprop ctl.stop wificond
setprop ctl.stop vendor.wifi-hal-1-1
setprop ctl.stop vendor.wifi_hal_legacy
setprop ctl.stop vendor.wifidisplayhalservice

# 4. 挂载 OpenWrt 环境
M=/data/local/tmp/lede
mkdir -p $M
mount -t ext4 -o rw /dev/block/sda25 $M
mount -o bind /dev $M/dev
mount -t proc proc $M/proc
mount -t sysfs sysfs $M/sys
mkdir -p $M/vendor && mount -o bind /vendor $M/vendor

# 5. 在 Mount 命名空间启动 OpenWrt 容器与服务
nohup unshare -m chroot $M /bin/busybox sh -c "
  export PATH=/usr/sbin:/usr/bin:/sbin:/bin
  mkdir -p /tmp /run /var/run/ubus /var/lock /var/log /etc/dropbear
  mount -t tmpfs tmpfs /tmp 2>/dev/null
  mount -t tmpfs tmpfs /run 2>/dev/null

  # 检查或补齐 Dropbear key
  if [ ! -s /etc/dropbear/dropbear_ed25519_host_key ]; then
    dropbearkey -t ed25519 -f /etc/dropbear/dropbear_ed25519_host_key
  fi

  # 启动核心进程
  /sbin/ubusd &
  sleep 1
  /sbin/procd &
  sleep 1

  # 启动 SSH
  /usr/sbin/dropbear -R -B -p 127.0.0.1:2222

  # 配置并拉起 Wi-Fi 与 DHCP
  ip link set wlan0 down
  ip link set wlan0 up
  ip addr flush dev wlan0
  ip addr add 192.168.10.1/24 dev wlan0

  killall dnsmasq 2>/dev/null
  dnsmasq -C /etc/dnsmasq-v50.conf

  killall hostapd 2>/dev/null
  hostapd -B -P /tmp/hostapd.pid /etc/hostapd/hostapd-5g.conf
" > /data/local/tmp/lede_takeover.log 2>&1 &

echo "=== [$(date)] OpenWrt Autostart Trigger Complete ==="
EOF

chmod 755 /data/adb/service.d/99-openwrt-takeover.sh
chown root:root /data/adb/service.d/99-openwrt-takeover.sh
'
```

#### 步骤 4.3：脚本静态与手工试运行核验
先不要重启，手工触发测试自启脚本执行逻辑，验证是否能顺畅跑通：
```bash
adb shell su -c "sh /data/adb/service.d/99-openwrt-takeover.sh"
adb shell su -c "cat /data/local/tmp/openwrt_autostart.log"
```
核验 OpenWrt 内部 `hostapd` 与 `dnsmasq` 依然稳定运行。

#### 步骤 4.4：实机物理冷重启验证（终极大考）
1. 执行物理重启：
   ```bash
   adb reboot
   ```
2. 等待设备完全开机（约 60-90 秒）；
3. 重新建立 ADB 端口映射并检测：
   ```bash
   adb forward tcp:2222 tcp:2222
   adb shell su -c "cat /data/local/tmp/openwrt_autostart.log"
   ssh -p 2222 -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null root@127.0.0.1 'iw dev; ps | grep -E "hostapd|dnsmasq"'
   ```
4. 物理客户端连接 `OpenWrt-V50-5G`，测试 DHCP 获取与 ping 网关连通性。
